# Network Traffic Anomaly Detection

## Project Description

This project is designed to analyze network traffic and detect whether the traffic is normal or anomalous.

The system captures network packets, extracts important features, preprocesses the data, and uses Machine Learning techniques to identify abnormal network traffic.

## Project Architecture

1. Network Traffic
2. Packet Capture
3. Feature Extraction
4. Data Preprocessing
5. Machine Learning
6. Normal Traffic or Anomaly Detection

## Technologies Used

- Python
- PyShark
- Pandas
- Machine Learning
- Wireshark
- GitHub

## Features

- Network packet capture
- Protocol identification
- Source and destination IP extraction
- Source and destination port extraction
- Packet length analysis
- Network traffic analysis
- Anomaly detection
